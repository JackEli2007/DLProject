Learn / Reference

A quick guide to digital logic, boolean algebra, and Karnaugh maps.

What is Boolean Algebra?

Boolean algebra is a branch of mathematics where the values of variables are true and false (usually denoted as 1 and 0). Unlike elementary algebra, where variables represent numbers and the main operations are addition and multiplication, the main operations of Boolean algebra are the conjunction (AND), the disjunction (OR), and the negation (NOT).

It forms the fundamental basis of all modern digital computer design, enabling engineers to design complex logical circuits by simplifying logical expressions.

What is a Logic Gate?

A logic gate is an idealized or physical electronic device implementing a Boolean function, a logical operation performed on one or more binary inputs that produces a single binary output. They are primarily implemented using diodes or transistors acting as electronic switches.

Logic Gate Summary

Gate Symbol Expression Description
AND · Y = A · B Output HIGH only when BOTH inputs HIGH
OR + Y = A + B Output HIGH when ANY input is HIGH
NOT ¯ Y = A̅ Output is the INVERSE of input
NAND (·)̅ Y = (A · B)̅ Output LOW only when BOTH inputs HIGH
NOR (+)̅ Y = (A + B)̅ Output HIGH only when BOTH inputs LOW
XOR ⊕ Y = A ⊕ B Output HIGH when inputs are DIFFERENT
XNOR (⊕)̅ Y = (A ⊕ B)̅ Output HIGH when inputs are SAME

Universal Gates

NAND and NOR gates are known as "Universal Gates" because you can construct any other boolean logic gate (AND, OR, NOT, etc.) using ONLY NAND gates or ONLY NOR gates.

This property is heavily utilized in integrated circuit design to reduce manufacturing costs, since a single type of transistor layout can be replicated to achieve any desired logic function.

Karnaugh Maps

A Karnaugh map (K-map) is a visual method of simplifying boolean algebra expressions. It organizes a truth table into a 2D grid where neighboring cells differ by exactly one bit (Gray code ordering).

What are Minterms and Maxterms?

  • Minterm: A product term (AND) where all variables appear exactly once. Denotes a '1' in the truth table.
  • Maxterm: A sum term (OR) where all variables appear exactly once. Denotes a '0' in the truth table.

Don't Care Conditions

In some systems, certain input combinations will never occur. These outputs are marked with 'X' (Don't Care). We can choose to treat an 'X' as a '1' or a '0' depending on whichever makes our groupings larger (and thus, our final expression simpler).

Gray Code Ordering

The sequence of inputs on the K-map axes follows Gray Code (e.g., 00, 01, 11, 10). This ensures that moving from one cell to an adjacent cell changes only one variable.

Grouping Rules

  • Groups must contain 1, 2, 4, 8, or 16 cells (powers of 2).
  • Groups can only be horizontal or vertical (no diagonals).
  • Groups should be as large as possible.
  • The grid wraps around (edges are considered adjacent).

Boolean Simplification from K-maps

After forming groups, write the simplified expression by observing which variables remain constant within each group. Variables that change (e.g. A is 0 in one part of the group and 1 in another) are eliminated.
